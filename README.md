# Автотесты для сайта ShareLane

Учебный практикум по автоматизации тестирования (Java + Selenium + JUnit 5 + Maven).

## Технологии
- Java 17
- Selenium WebDriver
- JUnit 5
- Maven
- Паттерн Page Object

## Структура проекта
- `src/test/java/base` — базовый класс с настройкой браузера
- `src/test/java/pages` — Page Object классы
- `src/test/java/tests` — автотесты

## Запуск тестов
```
mvn test
```
или зелёная стрелка рядом с названием класса в IntelliJ.
